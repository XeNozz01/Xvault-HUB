Cara join (4 langkah)

Siapkan GTA SA 1.0 US

Pastikan versi 1.0 (US/EN) dan tidak pakai mod yang mengganti samp.rsa. Mod grafis boleh, mod senjata tidak boleh.

Install SA-MP 0.3.7

Unduh installer resmi, jalankan di folder GTA SA. Setelah terpasang, buka samp.exe (bukan gta_sa.exe).

Tambah server

Tab Add Server → tempel play.xvaulthub.id:7777 → Add Selected → Connect.

Login & main

Gunakan /login password untuk akun lama, atau /register email password untuk akun baru. Pemain RP harus lolos whitelist.

Troubleshoot

“Unable to connect to server”

  1. Cek versi client — harus 0.3.7 (bukan 0.3.R1/0.3.DL).
  2. Ketik ulang IP manual, jangan pakai spasi.
  3. Matikan proxy/VPN; beberapa ISP memblokir port UDP tinggi.
  4. Coba port lain (mis. 7878) untuk memastikan bukan server penuh.

Ping tinggi / desync

Set fps_limit 50 di samp.cfg, matikan VSync, turunkan draw distance ke 200. Di sisi server, aktifkan lagsync compensation lewat /settings dasbor player.

Terpakat di antrean

Slot penuh saat prime time (19:00–01:00 WIB). VIP mendapat prioritas antrean, atau mainkan Beginner (port 8080) yang hampir selalu kosong.
